# Frontend

Next.js application for LabOS, written in React and TypeScript.

The starter renders one page so you can confirm that the dev server is running. It does not contain product screens.

Run it from the repository root:

```bash
make dev
```

| Path | Purpose |
| --- | --- |
| `app/` | Routes and the root layout |
| `components/` | Reusable UI |
| `hooks/` | Shared React hooks |
| `lib/` | Helpers that are not UI |
| `types/` | Shared TypeScript types |
| `public/` | Static files |
